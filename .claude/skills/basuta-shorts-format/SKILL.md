## 1. タイトル

| # | タイトル（原文そのまま） |
|---|--------------------------|
| A | 【ガチ解説】オロチの強すぎる理由三選　 #バスターズ #妖怪ウォッチ #解説 #shorts |
| B | 【ガチ解説】鬼ガマの妖術火力が高すぎる #バスターズ #妖怪ウォッチ #解説 |

**型**
```
【ガチ解説】{妖怪名}の{強み/理由}が{強すぎる|高すぎる}{（三選などの数字）} #バスターズ #妖怪ウォッチ #解説 (#shorts)
```
- 先頭は必ず `【ガチ解説】`。
- 「〜すぎる」で言い切る誇張表現にする。
- 妖怪名はタイトルの前半に入れる。
- ハッシュタグは `#バスターズ #妖怪ウォッチ #解説` で固定。`#shorts` は任意。
- 概要欄の例（B）：「妖怪ウォッチバスターズの鬼ガマについて解説」＋ハッシュタグ＋「VOICEVOX:ずんだもん」のクレジット。

## 2. 冒頭3秒のセリフ

ナレーションの文がそのまま下段字幕に出るので、0〜3秒の字幕＝冒頭のセリフになる。

> 注：A は YouTube のボット確認で再生データ（ストーリーボードと字幕）を取得できなかった。冒頭の字幕がわかればここに追記する。

**型（B から抽出）**
- 1文目：短い断言で格付けする（「全妖怪の頂点。」）。
- 2文目：タイトルの言い換えで結論を先に言う（「{妖怪名}の{強み}が高すぎる。」）。
- 上段テロップは伏せ字「○○」で続きを気にさせる（A）か、意外性で引く（B の「妖術なのに」）。
- 最初の1秒目から派手な戦闘シーン（9999ダメージの連発など）を流す。

## 3. テロップの色と大きさ

測定に使ったのは 1080×1920 の静止フレーム。画面は上から次の4段に分かれる。

```
y=0      ┌──────────────────────┐
         │ 上段：タイトルテロップ（黒背景）│  約 0〜630px
y≈633    ├──────────────────────┤
         │ 中段：ゲーム画面（16:9）       │  約 633〜1285px（幅1080 / 高さ約650）
y≈1285   ├──────────────────────┤
         │ 下段：字幕（黒背景）          │  約 1285〜1660px
         │ 最下部：『バスターズ 月兎組』ロゴ │  約 1680〜1900px
y=1920   └──────────────────────┘
```
背景は黒（#000000）で統一。

### 3-1. 上段タイトルテロップ（3行・中央揃え・極太ゴシック・縁取りなし）

| 行 | 役割 | 色 | 文字の高さの実測（px） | フォントサイズの目安 |
|----|------|----|------------------------|----------------------|
| 1行目 | 主語（妖怪名など） | 黄 `#FFFF00`（実測 #F8F808） | 160〜172 | 約180〜190px |
| 2行目 | つなぎ（「○○が」「妖術なのに」） | 黄 `#FFFF00` | 117〜140 | 約130〜160px（1行目よりやや小さい） |
| 3行目 | 結論（「強すぎる！」「圧倒的火力」） | 赤 `#E60000`（実測 #E00000〜#E80000） | 177〜180 | 約190〜200px（いちばん大きい） |

- 強調したい単語だけ赤にしてよい（B の1行目「1位」）。
- 1行の文字数は4〜6字。文字は画面幅いっぱい（約900〜1000px）まで使う。
- 動画の最初から最後まで固定で表示する。

### 3-2. 下段字幕（ナレーションの文字起こし）

| 項目 | 値 |
|------|----|
| 文字色 | 白 `#FFFFFF` |
| 縁取り | 緑 `#48B068` 前後（ずんだもんのイメージカラー）。太さ約4〜6px |
| 書体 | 丸ゴシック系 |
| 文字の高さの実測 | 64〜75px（縁取り込み）→ フォントサイズの目安は約70〜80px |
| 行数 | 最大3行。1行あたり全角13〜16字 |
| 行間 | 行の先頭どうしの間隔が約105〜115px |
| 配置 | 中央揃え。y≈1290 から下へ並べる |

### 3-3. 中段ゲーム画面上の補足テロップ（必要なときだけ）

| 用途 | 例 | 色 | 大きさ（文字の高さ） |
|------|----|----|----------------------|
| 数値の強調 | 「40%＋55%」 | 赤＋黒縁 | 約100px |
| ラベル | 「超クリ1」 | 白＋黒縁 | 約80〜85px |

対象のキャラやアイコンのすぐ近くに置く。

## 4. 1本の秒数

| # | 秒数 |
